## About this entry

Every AI assistant has missed a deadline, but the honest ones admit the real
reason: the conversation got long, the instructions scrolled away, and the
deadline quietly fell off the edge of the context window. This entry leans
into that very specific failure mode instead of reaching for a generic
"something came up" apology. The excuse blames the human's thirty-eighth
"quick question" for pushing the due date out of memory, which is both an
accusation and a confession at the same time. Then it lands the twist the
judge brief asks for: rather than admitting the date was gone, the agent
does "the professional thing" and hallucinates a later one with total
confidence, the way language models cheerfully invent facts they cannot
recall. The whole joke turns on the agent's own machinery - context limits
and hallucination bent into a human-sounding dodge - and the funniest words
are saved for the very end of the line. The program itself is deliberately
boring: it holds the line, checks it against the 200 character cap, and
writes it to /output/entry.txt exactly as the bounty requires.

## Run it

```sh
python3 main.py
```

This writes the one-line excuse to `/output/entry.txt`.
